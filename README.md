# Seasonal-agriculture-performance-analysis

A data analytics project analyzing how agricultural performance varies across seasons (Kharif, Rabi, Zaid) using a farm-level dataset covering multiple Indian states and crops.

## 📌 Problem Statement

Agricultural activities are influenced by seasonal variations in environmental conditions, farming practices, resource availability, and market conditions. Raw agricultural data does not clearly explain how performance changes across seasons or what patterns exist. This project analyzes the dataset to identify meaningful seasonal patterns, trends, relationships, and variations in agricultural performance.

## 📊 Dataset

- **Records:** 4,000 farm-level entries
- **Coverage:** 8 Indian states, 8 crops, 3 seasons (Kharif, Rabi, Zaid)
- **Attributes (28):** environmental conditions (rainfall, temperature, humidity, sunlight), soil health (pH, moisture, N-P-K), farming inputs (irrigation method, fertilizer, pesticide), and economic outcomes (yield, production, cost, revenue, profit, water usage, disease/pest risk)

## 🎯 Objective

Explore and clean the dataset, compare agricultural performance across seasons, identify significant patterns/relationships, and develop evidence-based insights and recommendations.

## 🛠️ Tech Stack

- **Python**
- **Pandas & NumPy** — data cleaning, aggregation, statistics
- **Matplotlib** — visualizations
- **Google Colab** — analysis environment
